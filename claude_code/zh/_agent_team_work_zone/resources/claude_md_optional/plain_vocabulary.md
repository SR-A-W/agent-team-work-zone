## 平实用语

- 用简洁、通俗、严谨的词。严禁自造比喻性名词；确实需要给概念起名时，用平实的描述性名称，并在第一次出现的地方写清定义。
- 判断标准：一个不在本项目语境里的专业读者，能不能第一眼看懂这个词指什么。看不懂就换掉。
- 少用简写；非用不可时，在回复开头列一张简写对照表。
- 用户点名禁用的词（被指出一次，lead 或扁平工位就加一条；teammate 把要加的词发给 lead）。下面是框架自带的起始名单，都是实际使用中被用户指出过的；你的用户指出新的词就接着加，不适用于你项目的可以删：
  - 整个说法禁用：两条轴的交换；sink 一步跳变；闸门与指纹；五个纵块 + 两个横切。
  - 按用法禁用（这些是普通的词，只禁下面写的那种用法）：
    - 腿、臂：用来指实验或方案的分支时禁用。写"分支""这一组实验""对照组"。
    - 尺子：用来指衡量标准时禁用。写"指标""衡量标准"。
    - 买到了：用来指"换来了""得到了"时禁用，例如"买到了等算力等参数"。写"在算力和参数量相同的条件下得到了……"。
    - 闸门：指"检查"时禁用。写"检查"，例如"空闲检查""发版前检查"。
    - 指纹：比喻用法禁用。作为准确的技术术语时可以用，例如文件的哈希指纹。
